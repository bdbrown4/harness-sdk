The .NET Standard Nova Sonic transport uses an internal C ABI over the native dependency commits shipped with AWSCRT 0.6.0. It uses AWS C Auth for SigV4 and chained event signatures, AWS C HTTP for manual HTTP/2 data writes, and Windows SChannel/CNG/IOCP for TLS, cryptography and sockets. It does not implement TLS, HTTP/2 or signing cryptography.

The managed adapter accepts a captured `ImmutableCredentials`, `RegionEndpoint` and model ID. Construction performs no network or native allocation. `OpenAsync` starts the input publisher before awaiting response headers. The SDK's normal Nova model owns the shared JSON/session/history/restart logic and the outer output reader. The native adapter owns and joins its input publisher, native stream/connection callbacks, bootstrap and event-loop shutdown. Caller-owned credentials are never disposed.

Both x86 and x64 release DLLs use `/MT` and expose the same ten undecorated C ABI symbols through the module definition file. ABI version 2 is checked before any native session opens. The private loader loads only the matching absolute assembly-relative `runtimes/win-x{64,86}/native/strands-nova-crt.dll`, using safe dependency lookup. It never changes process DLL search paths. Keep both native files nested when copying or publishing an AnyCPU Framework consumer.

For a source rebuild, create an isolated directory with this `CMakeLists.txt`, the `native/` bridge files and a `source/` directory containing the exact eight components listed in `source-pins.json`. Verify each downloaded archive's SHA-256 before extraction. The pinned source archives are small and do not require git submodule initialization. Use a Visual Studio 2022 C toolchain environment for the desired architecture, Windows SDK 10.0.26100.0, CMake and Ninja. Run `cmake -S <directory> -B <directory>/build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_POLICY_DEFAULT_CMP0141=NEW`, followed by `cmake --build <directory>/build --parallel 2`. Repeat with the other toolchain architecture in a separate directory. The CMake file selects embedded debug information and a static MSVC runtime for the bridge and dependencies. All native components' notices and licenses accompany the package.

Actual local verification passed 12 cases, including official SDK request/event signature comparisons, TLS HTTP/2 duplex before input EOF, blocked-write cancellation, exact caller cancellation, provider timeout mapping and separate net48-targeted x86/x64 probe processes. The host has .NET Framework 4.8.1 (registry release 534296); this does not qualify genuine .NET Framework 4.8. No live AWS request was made. Genuine 4.8, the normal composed Bedrock assembly and fresh NuGet/build/publish consumers remain separate acceptance gates. The proposed package targets are source-only until those gates run.
