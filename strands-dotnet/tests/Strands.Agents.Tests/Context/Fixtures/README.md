The eight cases in `shared-search.json` were generated by executing the TypeScript and Python search helpers at baseline `3bd98e618320f0f286acbfb2252f72388030421b`. Their outputs agreed byte for byte. The sources are `strands-ts/src/vended-plugins/context-offloader/search.ts` and `strands-py/src/strands/vended_plugins/context_offloader/search.py`.

These fixtures describe the shared search helpers, rather than the complete retrieval wrappers. The empty-content case supplies `line_range` so the native retrieval tool enters its search branch. Native empty-content search follows the Python wrapper/helper behavior; the TypeScript retrieval wrapper rejects empty text as non-searchable.

Invalid ranges are checked separately: the TypeScript helper returns an error string, while the Python helper raises `ValueError`. The native rich tool returns error status with the TypeScript error text. Native regex deadlines and a final output budget that includes headers and markers are additional explicit bounds.
