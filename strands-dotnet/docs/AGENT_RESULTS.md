# Safe result JSON and explicit rendering

`AgentResultJson.ToJson(result)` creates a detached native safe envelope. `AgentResultJson.FromJson(json)` reads that envelope with fresh empty local metrics and invocation state. Neither method restores an Agent, conversation, provider cursor or session.

The native envelope has `type: "strands.agent_result"`, integer `schemaVersion: 1`, `stopReason` and `message`. The message uses the native polymorphic content representation. This is separate from TypeScript/Python wire formats and Python byte wrappers.

The default `TypeScript` output profile includes a present `StructuredOutput`, including JSON null. The `Python` profile omits it and writes an absent checkpoint as JSON null. Both omit metrics, traces, caller invocation state and interrupts. Message metadata and supported provider replay data remain part of the native message; this API does not redact arbitrary application JSON. Local tool exceptions retain their existing JSON exclusion.

The private message serializer omits genuinely absent nullable fields. A present nullable JSON value whose kind is null remains a present JSON-null field. Nested JSON nulls, duplicate members and opaque provider data stay intact. Native constructor rules still apply: for example, external legacy/default message JSON containing `metadata: null` can be rejected because supplied message metadata must be an object. The API reads its own safe-v1 representation, not arbitrary default/foreign result graphs.

Rehydrated usage and turn counters are zero. Metrics are fresh and empty, context-size values are absent, and caller state, traces and interrupts are empty. This follows safe result projection semantics; it does not recover prior execution statistics.

`AgentResultRendering.Render(result, profile)` is opt-in. Both profiles prioritize pending interrupts, then accepted structured JSON, then selected message content. TypeScript text joins text, nonempty reasoning and citation fragments with LF and adds its reasoning header/indentation. Python text omits reasoning and appends LF to each text/citation fragment. Python pending-interrupt rendering uses a JSON-domain Python-style representation with a `None` response; native remote-agent requests have an explicit `remote-agent` presentation spelling. Native extra correlation remains on the original request.

Native and TypeScript JSON/numeric rendering retain their existing .NET contracts. Python pending-interrupt reasons and `SwarmContextTextProfile.PythonRepr` shared knowledge use a fixed JSON-domain projection based on CPython 3.10.2 and Unicode 13. Integer-form tokens use Python integer text; floating tokens use binary64 rounding and Python-style presentation, including negative zero, underflow and overflow. String escaping uses the pinned Unicode printability data, preserves printable astral characters and escapes lone UTF-16 surrogates. Duplicate object members select the last value in the first insertion position. This presentation does not rewrite the stored `JsonElement`, call arbitrary Python serializers, or establish equivalence across other Python/Unicode versions.

Python rendering of primitive/null structured JSON remains a native union extension; object JSON is the BaseModel-equivalent domain. Structured-result JSON rendering, opaque provider retention and the native/TypeScript paths remain separate from the Python text projection.

The existing five-argument `AgentResult` constructor, deconstruction, default JSON when the marker is absent, and `ToString()` remain unchanged. A present `Checkpoint` participates in record value equality and uses the native marker converter in default JSON. Default serialization of the whole live telemetry graph is not the safe API. Default message/session serializers also retain their separate nullable-JSON presence boundary; this private serializer does not change them.

`AgentResult.Checkpoint` carries the immutable experimental `AgentCheckpoint` marker. TypeScript projection includes it when present; Python projection always writes a marker or JSON null. Non-null input uses the accepted native schema1.0 converter, not Python snake_case wire or arbitrary falsey-value normalization. Stop reason and marker are independent representation data, matching the pinned result classes; neither grants resume authority. Agent pause/resume, provider-acknowledgment and session lifecycle support remain separate. Snapshot catalogs and tool-execution checkpoints do not substitute for that capability. Component checks do not establish latest combined-platform or complete parity coverage.
